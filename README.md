# 🎬 Video Grabaciones Gorilaz

Sitio web oficial de **Video Grabaciones Gorilaz** — estudio de videografía profesional en Contepec, Michoacán.

## 📁 Estructura del Proyecto

```
gorilaz/
├── index.html              # Página principal (home)
├── README.md
│
├── pages/                  # Páginas de cada servicio
│   ├── 15anos.html
│   ├── bodas.html
│   ├── bautizos.html
│   ├── aereas.html
│   ├── contacto.html
│   └── ubicacion.html
│
├── css/
│   ├── style.css           # Estilos globales + variables de color
│   └── animations.css      # Animaciones y transiciones
│
├── js/
│   └── main.js             # Interactividad general
│
├── images/
│   ├── logo/               # Logo del negocio
│   └── servicios/          # Imágenes de portada por servicio
│
└── videos/                 # Videos organizados por categoría
    ├── 15anos/
    ├── bodas/
    ├── bautizos/
    └── aereas/
```

## 🌐 Tecnologías
- HTML5
- CSS3 (responsivo, sin frameworks)
- JavaScript vanilla
- Google Fonts — Poppins
- Google Maps Embed

## 🚀 GitHub Pages
El sitio está pensado para publicarse en GitHub Pages directamente desde la rama `main`.
